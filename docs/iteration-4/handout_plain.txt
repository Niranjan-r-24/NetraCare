[H2] How the agent works

[P] Each patient message runs through a small LangGraph graph. The agent node loops with the tools node until it has an answer, and pauses for the patient before anything changes.

[OL] Red-flag node. Your code runs check_red_flags on the patient's message. A red flag ends here with the emergency response, an urgent case and no tool calls. Agent node. The LLM gets its instructions, today's date and a 30-day calendar, the patient's appointments and past visits, and the conversation. It replies, asks a question, or asks for one or more tools. Tools node. Runs the tools the LLM asked for and returns the results to the agent node. The loop repeats until the agent replies, up to a step limit. Confirm. Before a book, cancel or reschedule reaches the API, the graph pauses and the patient sees a card with Confirm and No. Nothing changes until they confirm. The API decides. The tool calls the same rules check as your website. A refusal comes back with its reason code, and the agent explains it and offers free times instead. Your code finishes the reply. It adds the sources from any document search, as in iteration 3, and shows the card or the answer.

[H2] Safety rules

[UL] Every chat message goes through the red-flag check first. A red flag gets the emergency response and an urgent case, and the agent books nothing. The API decides every booking, cancel and reschedule. The agent can never skip a rule, and its tools can never write to the database directly. Nothing changes until the patient presses Confirm. A late cancel or reschedule waits for Staff. The patient's ID comes from the login. The agent only ever sees and changes that patient's appointments. The chat never names a likely condition and never suggests treatment. Answers about policy or procedure show their sources, or "I don't know". If the red-flag check can't run, the chat doesn't answer or act.

[UL] The agent's prompt has no doctor notes or health details. It doesn't need them to book. Use only the data packs. Keep your API keys in .env , as before.
